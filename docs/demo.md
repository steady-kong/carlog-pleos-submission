# 공모전 시연

1. 대시보드에서 차량, 주행거리와 연비를 확인한다.
2. 주유 두 건과 소모품 주기를 입력해 연비와 교체 예정 상태를 확인한다.
3. MOCK 표기와 시뮬레이션 차량 신호를 확인한다.
4. 이벤트 유형과 메모를 입력하고 기록 버튼을 누른다.
5. 앱을 켜둔 채 60초 후 complete를 확인한다. 시작 후 60초가 지나기 전에 기록하면 전반 구간이 짧다.
6. 타임라인에서 이벤트를 열고 연료 그래프와 위치를 확인한다.
7. 정비 참고 리포트를 공유 화면으로 확인한다.

향후 정비 결과 연결을 통해 운전자와 정비사의 의사소통을 개선한다. 제조사 품질 분석은 별도 협력과 사용자 동의가 확보된 이후의 가능성이다. 현재 구현된 기능이 아니다.
