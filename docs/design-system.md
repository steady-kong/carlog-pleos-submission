# Carlog Graphite Blue 디자인 시스템

Carlog의 자동차용 화면은 차분한 그래파이트 블루를 행동과 선택 상태에 집중해 사용하고, 밝은 중립 표면과 분명한 정보 위계로 핵심 정보를 빠르게 읽도록 구성한다.

## 토큰

- 바탕은 `#F1F3F6`, 표면은 흰색, 보조 표면은 `#F7F9FB`, 미세 표면은 `#E8EBF0`, 테두리와 구분선은 `#E0E4EA`를 사용한다.
- 기본 글자는 `#192536`, 보조 글자는 `#526071`, 설명 글자는 `#748091`이다. Graphite Blue 주 색상은 `#243248`, hover는 `#31445E`, pressed는 `#192638`, 옅은 선택 배경은 `#E9EEF9`다.
- 성공·주의·오류·정보 상태는 각각 녹색 `#18855A`, 황토색 `#BC7A21`, 빨강 `#C7474D`, 파랑 `#5573BA`로 구분한다.
- 간격은 8, 16, 24, 32dp 단계를 기본으로 한다. 주요 터치 영역 최소 높이는 64dp, 카드 모서리는 16dp, Hero 액션 모서리는 20dp다.
- 본문은 14–18sp 범위에서 계층화한다. 주요 수치는 32–36sp의 굵은 tabular 숫자로 표시하고 단위는 작게 분리한다.

## 컴포넌트 역할과 정보 위계

`CarlogDesign.kt`는 색상·간격·타이포그래피·Material 테마의 원천이다. 이벤트 화면의 가장 중요한 동작은 그래파이트 블루 면 전체가 하나의 터치·접근성 타깃인 `CarlogHeroAction`이며, 기본 문구는 `지금 이벤트 기록`, 요청 중 문구는 `기록 시작 중`이다. 음성 기록 등 보조 동작은 외곽선 버튼인 `CarlogSecondaryAction`으로 분리하고, 테스트·유틸리티는 `CarlogUtilityPanel`에 묶는다.

상단 탭은 `이벤트`, `차량 관리`의 짧은 이름을 사용한다. 선택 탭은 옅은 Graphite Blue 배경과 주 색상 글자로 구분하고, 비선택 탭은 중립 배경과 보조 글자로 유지한다. 주 색상은 넓은 장식 영역에 반복하지 않고 주요 CTA와 선택 상태에 집중한다.

`HmiComponents.kt`는 기록·마이크·완료·경고·이력 기호, 진행/성공/주의/오류를 표현하는 `HmiStatus`, 안내용 `HmiEmptyState`를 제공한다. 아이콘은 장식으로 쓰고 인접 텍스트가 동작 이름을 제공한다. 상태 변경은 적절한 경우 접근성 live region으로 알린다.

`ManagementDashboard.kt`는 차량 이름과 현황, 기록 주행거리·연료·배터리, 평균 연비와 이번 달 지출, 주유·정비 내역, 월별 지출 추이 순으로 정보를 배치한다. 지표 값은 크고 굵게, 단위는 작게 보여주며 기록이 없거나 정보가 부족한 경우 그 상태를 직접 표시한다. 좁은 폭에서는 지표 열을 줄이고, 유효한 백분율 신호에만 잔량 막대를 표시한다. 월별 추이는 서로 다른 월의 실제 기록이 두 개 이상 있을 때만 표시한다.

## 유지하는 동작

시각 표현을 바꿔도 이벤트 기록·수집·상태 표시와 차량 관리 데이터를 유지한다. 빈 기록, 진행 중, 완료, 오류를 구별하고 기록에 없는 값을 만들어 내지 않는다. 시각적 진행은 수집 완료를 앞당겨 뜻하지 않으며 잔량·금액·연비의 출처와 실제/Mock 구분을 유지한다. 반응형 배치, 최소 터치 높이, 포커스·눌림 피드백도 유지한다.

## 이벤트 그리드

700dp 이상에서 조작 영역과 최근 이벤트 영역을 55:45로 배치한다. 두 영역은 같은 상단 기준과 24dp 내부 패딩, 16dp 콘텐츠 간격을 사용한다. 각 열은 콘텐츠 높이를 독립적으로 유지하며, 동일 높이 강제·화면 높이 기반 최소 높이·최근 목록의 외곽 배경 패널을 사용하지 않는다. 최근 이벤트는 실제 기록을 최대 3개 우선 표시하고, 0개일 때 작은 아이콘과 안내 한 줄을 표시한다. 좁은 화면은 세로로 배치하며 긴 내용은 기존 바깥 스크롤로 확인한다. 전체 작업 진행은 왼쪽 Status Strip, 개별 이벤트 상태는 오른쪽 목록에서 표시한다.
